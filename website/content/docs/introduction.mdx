Emblor gives you the keyboard behavior, validation, focus management, form values, and screen-reader announcements a
tag input needs. You choose the markup and styling.

## The smallest complete field

Install the one public package and import from its root. A `TagList` render function receives the exact current string and positional index.

```tsx title="TypeScript"
import { EmblorInput, EmblorLabel, EmblorRoot, EmblorTag, EmblorTagList, EmblorTagRemove, EmblorTagText } from 'emblor';

export function SkillsField() {
  return (
    <EmblorRoot defaultValue={['react']} name="skills">
      <EmblorLabel>Skills</EmblorLabel>
      <EmblorTagList>
        {(tag, index) => (
          <EmblorTag key={tag} index={index}>
            <EmblorTagText />
            <EmblorTagRemove aria-label={`Remove ${tag}`} />
          </EmblorTag>
        )}
      </EmblorTagList>
      <EmblorInput placeholder="Add a skill" />
    </EmblorRoot>
  );
}
```

## What Root owns

`EmblorRoot` stores the committed `string[]`, draft text, validation result, focus state, native form values, and private
screen-reader announcements. Control both values through Root; `EmblorInput` does not have a separate value API.

Use `defaultValue` for uncontrolled committed values. Use `value` and `onValueChange` for controlled values. Draft control is a separate Root concern with `defaultInputValue`, `inputValue`, and `onInputValueChange`.

## What you own

Your application supplies React keys, optional occurrence IDs, markup, CSS, suggestion menus, sorting, form adapters,
and visible error messages. The integrations on this site are examples you can copy; they are not package exports.

<DocsCallout type="note">
  Import Emblor components from `emblor`. Keep optional libraries such as shadcn, React Hook Form, and drag-and-drop
  utilities in your application.
</DocsCallout>
