# Emblor

Unified headless tag input primitives with modular subpath exports:

```ts
import { EmblorRoot } from 'emblor/core';
import { ClearButton } from 'emblor/addons';
import { useKeyboardSortable } from 'emblor/sortable';
```

The package ships tree-shakable ESM/CJS bundles and TypeScript types for all submodules. See the `playground/` app for composition examples.
