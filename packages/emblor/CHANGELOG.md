# emblor

## 2.0.0-alpha.0

### Major Changes

- Emblor v2 is a deliberate breaking release that narrows the package to a headless compound tag-input primitive. The public value model is now `string[]`, the supported API is the root-only compound surface, and v1 integrations, feature subpaths, styling, autocomplete, sorting, and drag-and-drop are not included. See `MIGRATION.md` for the v1-to-v2 conversion guide.
